# SWF 原生网页迁移

产物是直接运行原生 JavaScript 的网页游戏。SWF 仅作离线逆向输入和原版基准；本 skill 是迁移工作流，不承诺自动把任意 SWF 转成等价 HTML。

## 保持任务边界

- 从用户上下文确定目标游戏、源版本、发布位置和保真要求。已有授权继续沿用；仅在缺项会影响实现时澄清。
- 用户要求原版时，核对目录分类、实际 SWF 和哈希，排除 reskin/换皮条目。名单待用户选择时只盘点，不擅自批量迁移或恢复下架入口。
- 原版可以在独立的 Ruffle/Flash 基准页运行。迁移版不得嵌入 Ruffle、AVM、SWF 字节码解释器，或把同一 SWF 换壳后称为原生版。
- 复用原矢量、位图、字体和声音；缺失时先定位原件或明确缺项，不凭截图重画、生成替代音效或设计近似玩法。
- 原始异常行为也属于对照内容。改错、规则调整、额外操作方式需区分为适配或改动，不能悄悄合理化。

## 固定原件与逆向证据

先建立一份来源记录：源仓库提交、SWF 相对路径、SHA256、字节数、舞台 RECT、FPS、AS2/AS3、导出工具版本。保留原件不改；旧目录链接和标题可能指错文件，以实际文件与哈希核验。

提取脚本、标签/XML、主/子时间轴、实例名和深度、按钮四态与声音绑定，以及矢量、位图、字体、原始音频。按需使用 FFDec/JPEXS 或格式解析工具；先读取当前工具帮助，不猜 CLI 参数。导出失败不等于原件没有素材或逻辑。

在移植复杂动画、碰撞、时间或声音之前，读取 [Flash 迁移细节](references/flash-migration.md)。该文件涵盖导出缺损、运行时量化、多个时钟、子实例保留和音频事件。

建立简短的来源映射：

| 原件证据 | 原生实现 | 验证方式 |
| --- | --- | --- |
| AS 方法/帧动作、常量和随机调用 | JS 状态、调度和规则 | 独立规则差分、边界用例 |
| symbol ID、深度、矩阵、颜色变换 | 静态资源、Canvas 绘制与时间轴 | 显示列表检查、相同状态画面对照 |
| Sound ID、绑定实例、事件/帧、SOUNDINFO | 音频表与触发逻辑 | ID/事件核验、实际播放试听 |
| 宿主方法/外部请求 | 明确的集成边界 | 本地玩法与外部功能分开验证 |

不要把大量无关原始导出塞进发布目录。协作记录遵循目标 workspace 约定，源码进入目标仓库；共享 skill 只保存通用方法，不包含本机路径或账号。

## 实现原生游戏

- 先迁移可核验的规则状态，再接入原显示列表、动画、输入和声音。按实际游戏组织模块，避免为了通用化重新写一个 SWF/AS 虚拟机。
- 静态矢量可以转换成 SVG、Canvas 路径或离线图集；保留原变换、层级和碰撞数据。允许必要的静态绘图辅助代码，检查其来源和许可；不把导出的完整播放器当游戏实现。
- 保留时间轴帧率、独立 timer、事件顺序、随机数调用顺序、重置和销毁语义。浏览器刷新率不能直接充当原游戏逻辑速度。
- 每类对象、动作和场景分别映射原声音。即使都属于“捕获”，不同对象也不能默认共用一段音效；是否不同以及各自触发时机必须由所选 SWF 确认。
- 旧账号、积分、兑换和客户端宿主调用单独列出。必要初始化与纯提交积分区分；无法还原的服务明确说明，不伪造成功或悄悄删掉核心玩法。

## 手机与独立 HTML/ZIP

保留原舞台逻辑坐标和宽高比。CSS 决定显示尺寸，Canvas backing store 按 DPR 提高清晰度；pointer 坐标通过实际 bounding rect 反算回原舞台。检查浏览器额外缩放、旋转、安全区和横向溢出。

按原输入语义映射触摸：按下、移动、释放、取消、离开边界和 active pointer 分别处理。输入方式可以适配，计分、节奏、碰撞和关卡规则保持原样。

目标为上传 HTML/ZIP 小工具时，资源随包提供、路径可移植。保留解码/音频启动所需的用户手势。平台有专用容器或 SDK 时，按当前官方规则和实际容器另验；不能把普通网页包称为已通过平台。

## 验证与交付

读取 [对照与交付验证](references/verification.md)，按实际完成范围保存证据。至少核对菜单、说明、开局、不同对象/输入、计分、计时、关卡、失败/结束、重玩和声音；某游戏不存在的分支无需臆造。

逐款通过再加入公开目录。入口旁的原版对照链接必须指向正确游戏和原件；不能两侧都运行原 SWF。

构建包检查运行依赖、资源闭包、许可与来源。原 AS/测试 VM 可以留在离线测试中，但不得进入运行包。严格独立包不包含 SWF/Ruffle/AVM、隐藏字节码执行、`eval`/`new Function` 或未说明的网络加载；本工作流默认不引入 WASM 运行依赖。若用户明确选择另一种技术路线，先说明与当前原生 JS 交付目标的差别。

报告给出源身份、原生实现与线上/ZIP 入口、实际测试结果、已知差异和未测范围。只在证据支持的层级说“通过”，不要把能打开、单元测试或缩放截图当作完整保真验收。
