# 安装、权限与首次验证

此流程用于支持 Computer Use 的 macOS 桌面环境。`mcp__cua_repl` 是 Agent 使用的工具入口：借助客户端 AX 文字、截图和界面操作读取内容。本方法未使用企业微信业务 API，无需为此创建企业微信开发者应用。

## 按界面配置

1. 在桌面端选择 **Codex** 或本地 **Work**，打开 **Plugins → Computer Use**，按提示选择 **Install plugin** 或 **Enable**。
2. 在该插件中同时打开 **Computer Use MCP server** 和 **Computer Use skill** 开关，再选择 **Try now**。这里的内置 skill 与 `wecom-desktop-reading` 分工不同：前者配合桌面工具，后者提供企业微信读取步骤。
3. 在 macOS **系统设置 → 隐私与安全性** 中，为系统提示的实际组件（通常显示为 **Codex Computer Use**）开启 **辅助功能** 和 **屏幕录制**。若系统提示重启应用，按提示执行。
4. 在桌面端 **Settings → Computer use** 检查应用访问；首次访问时批准企业微信。用户可按需要保留该应用的授权。随后正常登录企业微信，打开本次授权的目标页面。

以上入口与权限依据 [官方 Computer Use 文档](https://learn.chatgpt.com/docs/computer-use)，界面名称可能随版本变化。macOS 系统权限、桌面端应用批准、企业微信登录态是分别检查的前提。权限提示须由用户处理，Agent 不代为批准。

## 分项验证能力

在用户已授权的目标应用中验证，不以打开了窗口作为全文读取成功的证据：

| 层级 | 验证方法与通过标准 |
| --- | --- |
| 工具入口 | 当前会话的工具清单确实提供 `mcp__cua_repl`；没有入口时先处理插件或会话环境。 |
| 应用识别 | 首次调用只执行下面一个入口，阅读返回文档，确认识别到企业微信或得到明确的应用访问结果。 |
| AX 文字 | 按运行时文档读取 AX，能识别本次目标标题、日期或正文；只有窗口控件时继续诊断，不标为正文可读。 |
| 截图 | 按运行时文档获取目标窗口截图，确认来自同一目标；失败则分别记录 AX 和截图的实际能力，不能宣称全部就绪。 |

首次调用示例（不要同一调用中追加点击或截图）：

```javascript
let wecom = await cua.getApp("com.tencent.WeWorkMac");
```

后续调用以入口返回的当前 API 文档为准。已有或压缩过的会话按主 skill 的恢复要求执行，不重复声明已有变量。诊断记录只保留通过项、缺失项与错误类型；原始 AX、截图和私有窗口标题不写入共享库。

## 缺项处理与其他 Agent 环境

- **无工具入口：** 检查 Computer Use 是否对当前账号可用、插件 server 与 skill 是否启用，以及当前会话是否接入该桌面宿主。功能不可用或受组织限制时说明具体缺项。
- **应用访问被拒：** 核对桌面端应用批准；若错误指出系统权限缺失，再核对 macOS 对应权限。不要通过重复请求批准绕过管理员限制。
- **AX 只有外壳，或截图／坐标操作失败：** 按 [窗口与读取恢复](recovery.md) 选择有证据的恢复动作；不要盲目重装插件或直接判定文档为空。
- **通用 CLI、第三方 Agent 或远程会话：** 先确认实际执行宿主能控制已登录企业微信的那台机器，并提供同名 REPL 或功能等效的桌面工具。此处验证的是桌面产品接入方式，不提供可通用于所有 Agent 的 MCP 服务地址、启动命令或 JSON。其他工具使用其自身文档，不能照搬方法名。
- **换模型：** 工具、系统权限、应用批准、宿主及目标窗口一致后，再比较模型表现；skill 不赋予工具能力，也不保证所有模型都能完成相同操作。

## 可直接转发的配置与操作概要

> 在支持 Computer Use 的 macOS 桌面端进入 Plugins → Computer Use，安装／启用并同时打开 MCP server 与内置 skill；在系统设置 → 隐私与安全性中为提示的组件开启辅助功能和屏幕录制，再按提示批准企业微信并正常登录。确认目标 Agent 有 `mcp__cua_repl`；首次只调用 `cua.getApp("com.tencent.WeWorkMac")` 并阅读返回文档。随后优先用 AX 读取文字和表格，必要时截图、点击、滚动及切换窗口；每次动作后核对目标和正文，确认分页、行对应与全文覆盖后逐份保存。按只读授权执行，共享材料去掉账号、客户和业务正文。可使用 `$wecom-desktop-reading`；仅复制 skill 不会安装工具，其他宿主需先接入相应桌面能力。
