# ChatArch Operations Skills

ChatArch service operations, release/readiness, DNS/certificate, and service-control workflows.

## Skills

- `chatdns-certificate-operations/` — ChatDNS-managed DNS records and certificates, with generic server-install patterns.
- `chatglance-service-entry/` — Register verified services through the reviewed catalog, default inline SVG covers, monitoring, validated refresh, and browser acceptance.
- `chatimg-image-generation-modes/` — Generate images with ChatImg via API-key OpenAI-compatible routing or OAuth/access-token routing, with proxy and redaction rules.
- `chatpypi-tool-service-operations/` — Configure and consume ChatPyPI local/service CLI, authenticated REST/MCP tools, account bindings, and artifact-only uploads.
- `chatvoice-speakr-operations/` — Operate ChatVoice/Speakr runtime, provider cutovers, release/readiness, and visual acceptance workflows.
- `crs-service-operations/` — CRS / Claude Relay Service and ChatCRS HTTP-first operations, runtime token store, and release verification workflows.
- `file-share-web-ui-auth/` — Build application-owned auth and upload UX for file-share web UIs with permission boundaries.
- `harbor-registry-operations/` — Operate Harbor deployments and registries with native auth, the official CLI, real OCI push/pull acceptance, and least-privilege CI credentials.
- `managed-file-share-publication/` — Publish files and directories through managed ChatShare/Dufs services with public readback gates.
